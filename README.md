# Construction Planner

โปรแกรมวางแผนและติดตามงานก่อสร้างสำหรับ **ผู้รับเหมา** — รันในเครื่องตัวเอง เปิดผ่านเว็บเบราว์เซอร์

| แท็บ | ทำอะไร |
|---|---|
| ภาพรวม | % แผน vs จริง, SPI, วันคาดว่าเสร็จ, ค่าปรับประมาณการ, งวดถัดไป, ตรวจความถูกต้องของข้อมูล |
| Gantt | แผนงานรายชั้น/หมวด, สายงานวิกฤต, Baseline, เส้นวันสิ้นสุดสัญญา, แก้ระยะเวลา/ลำดับงาน, Export Excel |
| กรอกความคืบหน้า | ตาราง ห้อง × หมวดงาน ติ๊กตามขั้นตอนงาน (ใช้บนมือถือได้) |
| แบบแปลน | ระบายสี % ลงบนแบบรายห้อง / เทียบแผน / คลิกห้องเพื่อบันทึก % และแนบรูป |
| S-Curve | แผน / ผลงานจริง / คาดการณ์ / แผนเบิก / เบิกจริง |
| งวดงาน | เช็คเงื่อนไขงวดอัตโนมัติ, บันทึกยื่น-อนุมัติ-รับเงิน, **ใบขอเบิก** (พิมพ์/PDF/Excel) |
| VO / EOT | งานเพิ่ม-ลด, ขอขยายเวลา, ค่าปรับล่าช้า |
| BOQ | รายการ BOQ ทั้งหมดและการผูกกับหมวดงาน |

มีโครงการให้ดู 2 ชุด: `machi-demo` (มีความคืบหน้าจำลองไว้ให้ดู) และ `machi` (โครงการเดียวกัน เริ่มจาก 0%)

## ติดตั้งบน Windows (ครั้งแรก)

1. ติดตั้ง **Python 3.9 ขึ้นไป** จาก https://www.python.org/downloads/
   ตอนติดตั้ง **ติ๊ก "Add python.exe to PATH"** ด้วย
2. ติดตั้ง **Git** จาก https://git-scm.com/download/win (ถ้าจะใช้ git clone)
3. ดาวน์โหลดโปรแกรม
   ```
   git clone https://github.com/Tes-27/construction-planner.git
   ```
   หรือกดปุ่ม **Code → Download ZIP** บน GitHub แล้วแตกไฟล์
4. เข้าโฟลเดอร์ แล้ว **ดับเบิลคลิก `start.bat`**
   - ครั้งแรกจะสร้าง `.venv` และติดตั้งแพ็กเกจ (ต้องต่ออินเทอร์เน็ต ใช้เวลาราว 1–2 นาที)
   - เบราว์เซอร์จะเปิด http://localhost:5070 ให้เอง
   - ปิดหน้าต่างดำ (Command Prompt) = ปิดโปรแกรม

### เปิดโครงการอื่น / ใช้มือถือ
```
start.bat machi            เปิดโครงการ machi (ชื่อโฟลเดอร์ใน projects\)
start.bat machi-demo --lan ให้มือถือในวง Wi-Fi เดียวกันเข้าได้ (โปรแกรมจะบอก URL)
```
- เปลี่ยนโครงการในโปรแกรมได้จากช่องเลือกมุมบนซ้ายเช่นกัน
- ใช้ `--lan` แล้ว Windows อาจถามเรื่อง Firewall ให้กด **Allow** (เฉพาะ Private network)
- โหมด `--lan` **ไม่มีรหัสผ่าน** — ใช้เฉพาะ Wi-Fi ที่ไว้ใจ (สำนักงาน/บ้าน) ไม่ใช่ Wi-Fi สาธารณะ

## ติดตั้งบน Mac
ติดตั้ง Python 3 แล้วดับเบิลคลิก `Construction Planner.command` (ครั้งแรกถ้าเปิดไม่ได้: คลิกขวา → Open)

## ใช้กับ Claude Code

เปิดโฟลเดอร์นี้ใน Claude Code แล้ว Claude จะอ่าน `CLAUDE.md` เองอัตโนมัติ (อธิบายโครงสร้าง กฎ และวิธีทดสอบไว้แล้ว)

**รับโครงการใหม่** — ส่งไฟล์ BOQ (Excel), แบบก่อสร้าง (PDF), ตารางงวดงาน และระยะเวลาสัญญาให้ Claude แล้วพิมพ์
```
/new-project ชื่อโครงการ
```
Claude จะแปลงไฟล์ที่รูปแบบไม่เหมือนกันเป็นโครงการในโปรแกรม ตามขั้นตอนใน `INGEST.md` (ทุกโครงการใช้โปรแกรมเดียวกัน — เขียนเฉพาะตัวแปลงใหม่)

**ตัวอย่างสิ่งที่สั่งได้**
- "เพิ่ม VO ตัดงานราวระเบียงชั้น 2 มูลค่า 40,000"
- "ห้อง Type B จริงๆ คือห้อง X36 แก้ให้หน่อย"
- "ปรับแผนให้งานผนังชั้น 3–5 ใช้เวลาเพิ่มอีก 5 วัน"
- "ทำใบขอเบิกงวด 7 ให้ตรงแบบฟอร์มของผู้ว่าจ้าง (แนบไฟล์แบบฟอร์ม)"

## เอกสาร
| ไฟล์ | สำหรับ |
|---|---|
| `CLAUDE.md` | Claude — โครงสร้าง กฎ การคำนวณ หลุมพราง |
| `DESIGN.md` | การออกแบบ รูปแบบข้อมูล และสถานะแต่ละเฟส |
| `INGEST.md` | ขั้นตอนแปลงไฟล์โครงการใหม่ |

## ทดสอบ
```
.venv\Scripts\python.exe -m unittest discover -s tests -v
```
(Mac: `.venv/bin/python -m unittest discover -s tests -v`)

## ข้อมูลอยู่ที่ไหน
ทุกอย่างเป็นไฟล์ในโฟลเดอร์ `projects/<ชื่อ>/` — สำรองข้อมูล = คัดลอกโฟลเดอร์นี้
ความคืบหน้า (`progress.csv`), สถานะการเบิก (`billing.json`), VO/EOT, รูปถ่าย (`photos/`) ถูกบันทึกเพิ่มตอนใช้งาน
